# Munadi APK

Signed APK releases for **Munadi**, a lightweight, privacy-focused prayer-times app for Qatar.
The source repository is private.

## Download

Get the latest signed APK from the [Releases page](https://github.com/hackills/munadi-apks/releases/latest).
Each release provides a `munadi-<version>.apk` asset.

## Privacy

No accounts, no ads, no analytics, no trackers. Settings and timetable data stay
on your device, and location is approximate only. Read [PRIVACY.md](PRIVACY.md).
